Spacing & grid

Mobile-first 12-column grid, max content width 1280px, 16–24px gutters. Section rhythm: eyebrow → heading → content, with generous vertical padding (56–80px).

Motion

  • Hover. Card image zoom (1.05), headline colour shift, 150–300ms ease-out
  • Reveal. Subtle fade-up on hero content, 600ms ease-out
  • Focus. Visible 2px green focus ring for keyboard users
  • Filtering. Instant, client-side content switching with no page reload

Accessibility

Brand green #006C53 meets WCAG AA against white (≈5.7:1). Body text uses near-black. All interactive elements expose visible focus states and semantic landmarks.

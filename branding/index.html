Spacing & grid

Mobile-first 12-column grid, max content width 1280px, 16–24px gutters. Section rhythm: eyebrow → heading → content, with generous vertical padding (56–80px).

Motion

  • Hover. Card image zoom (1.05), headline colour shift, 150–300ms ease-out
  • Reveal. Subtle fade-up on hero content, 600ms ease-out
  • Focus. Visible 2px blue focus ring for keyboard users
  • Filtering. Instant, client-side content switching with no page reload

Accessibility

Brand blue #0082F0 carries accents, buttons and large headings, while the darker #0069C2 is used for body links and icons that need AA contrast on white (≈5.0:1). Body copy is near-black on white. All interactive elements expose visible focus states and semantic landmarks.

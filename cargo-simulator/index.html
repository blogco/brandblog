Configure GitHub history sync

Enter a fine-grained GitHub personal access token with Contents: write access to blogco/brandblog. It is sent directly from this browser to GitHub and is never included in AWB records. Synced records are public, so use fictional data only.

A token saved in localStorage can be accessed by scripts running on this site. Use the minimum repository scope, do not use an organization-wide token, and revoke it when no longer needed. Leave “Remember” unchecked to keep it only for this page session (the token is not saved for future sessions).

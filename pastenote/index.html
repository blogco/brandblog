Pastenote

Dán mọi thứ khẩn cấp — link, ảnh hoặc text — thành giấy note 3M Post-it. Tự động lưu trên máy, sẵn sàng đồng bộ lên GitHub.

Chưa có ghi chú nào

Dán một link, ảnh hoặc đoạn text vào ô phía trên (hoặc nhấn Cmd/⌃+V ở bất kỳ đâu) để tạo giấy note đầu tiên.

Đồng bộ lên GitHub

Nhập GitHub Personal Access Token để commit bảng ghi chú lên repository.

Bảo mật: token chỉ được dùng trực tiếp từ trình duyệt của bạn để ghi vào content/data/pastenote.json và chỉ lưu trên máy bạn — không được commit lên repository này. Hãy dùng token có quyền tối thiểu (contents:write) và thu hồi nếu bị lộ.
